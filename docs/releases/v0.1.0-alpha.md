## Cascade Vision alpha preview

This prerelease packages the documented Cascade Vision pipeline as a separate preview.
It includes local motion filtering, object detection and tracking, asynchronous
vision-language model inspection, JSON reports and JSONL event export.

The package version is `0.1.0a0` under Python's version scheme. Download the wheel
attached to this release and run the following from its download directory.

```bash
python -m pip install ./cascade_vision-0.1.0a0-py3-none-any.whl
cascade-vision demo --mock-vlm --event-labels person,backpack --report-json reports/demo.json --events-jsonl reports/events.jsonl
```

The demo uses synthetic footage and simulated model output. It produces a run
summary and event records without credentials or external API calls.
