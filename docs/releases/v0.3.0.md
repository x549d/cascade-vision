An early-alpha release focused on failure recovery, transparent events and reproducible evaluation tooling.

Changes:

- Bounded fresh-frame retries, exponential backoff, non-retryable response handling and pending-request suppression.
- TTL/frame-based verdict refresh, static-scene detector refresh and stale queue expiration.
- Thread-safe JSONL events with provider usage, queue/service/end-to-end timings, failures and stream epochs.
- Bounded RTSP reconnects with FFmpeg timeouts and protection against results from old connections.
- Annotated local-video comparisons for interval, motion, cascade and full-frame policies, event episode matching and paced event latency.
- Explicit simulation/synthetic-footage/loss/budget quality flags and a shared request-attempt cap.
- Synthetic fixture generator, real-video manifest, pilot feedback template, integration guide and proposed six-month maintenance plan.

Validation: automated offline regression tests, lint/format checks, synthetic comparisons, source/wheel build and metadata validation. See the commit's CI checks for the tested Windows/Ubuntu and Python matrix.

Scope: no independently validated real-video accuracy, savings or adoption is claimed. Real evaluation needs authorized footage, annotations and an explicit API budget. The synthetic example is only a smoke test.

Migration: periodic refresh can increase API calls. Set `max_vlm_calls` / `--max-api-calls` to bound attempts. Use `get_verdict()` for TTL-aware cache reads. Refused/non-retryable and retry-exhausted tracks require explicit reset or track expiry before another cycle. The event/report additions are documented in README and docs/EVENTS.md.

Install the attached wheel, or install the tagged source with `python -m pip install ".[yolo]"` when a real detector is required. Third-party models and packages retain their own licenses.
