# Independent pilot guide

Status: recruitment materials only. No independent pilot participants or outcomes are claimed.

## Suggested pilot

1. Install a tagged release in a fresh environment, then run the synthetic demo and save JSON/JSONL outputs.
2. Select a short constant-frame-rate clip you are authorized to process. Keep private video local. Record its license or permission and annotate observable event intervals.
3. Choose an explicit provider model, input/output prices and a small maximum number of API attempts. Understand that each admitted request, including retries, can incur charges. An attempt cap is not a dollar ceiling.
4. Run interval, motion and cascade comparisons with the same vocabulary, footage and model. Use paced replay for event-to-verdict latency.
5. Inspect failures, queue loss, API usage and event recall. Report negative results as well as improvements.
6. Submit a sanitized issue using the pilot feedback template. Sharing your name, organization, footage or logs is optional.

- Release/commit, machine and dependency versions.
- Real integration use case and policy comparison results.
- Sanitized bug reports, maintainer responses and fixes.
